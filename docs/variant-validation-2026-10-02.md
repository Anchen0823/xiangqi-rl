## 普通象棋回归的已知边界

普通象棋 TypeScript 与原生规则回归通过，原 `.xqgame`、NNUE、训练入口保持原接口。完整 Python 训练回归执行 99 项，97 项通过，2 项失败：

- `test_games_split_with_cross_split_dedup`：工作区已有实现保留同一划分内的重复样本，而测试要求全局每个 FEN 只出现一次。
- `test_dedup_ignores_move_counters`：同一棋盘不同计数按已有实现保留到同一划分，实际保留 60 条；测试先要求保留 120 条，又要求每个棋盘键唯一，两个断言互相不一致。

这两项涉及本任务开始前已有的 `trainer/src/xiangqi_nnue/split.py` 与 `trainer/tests/test_split.py` 修改。本次没有覆盖或改写这些文件，也没有把整套 Python 回归宣称为通过。夜间划分和时间预算测试通过。

原标准象棋的完整正式比赛循环棋例、长杀等裁决覆盖仍需独立验证；本轮 2,000 局面检查只证明合法着法相符，不为正式棋例完整性背书。新增模式明确使用 lab-v1 实验裁决。
