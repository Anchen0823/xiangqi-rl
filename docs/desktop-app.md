# 弈境桌面应用

Windows x64 免安装版：完整解压文件夹，双击 **弈境.exe**。
无需安装 Node.js、Python 或联网下载模型。可将整个文件夹移动到其他目录，不能只复制 exe。

四个模式为平级入口：普通象棋、变体实验室、揭棋、翻棋。

| 模式 | 随包权重 |
| --- | --- |
| 普通象棋 | 2026-09-30 续训 NNUE 候选，由 Pikafish 加载 |
| 揭棋 | 2026-10-03 独立训练候选，182 个训练局、1000 次更新 |
| 变体实验室 | 8 局、100 次更新的短训实验候选，仅匹配原规则 |
| 翻棋 | 8 局、100 次更新的短训实验候选 |

进入模式自动检查并加载对应权重。重新开局、取消搜索后仍自动加载。
改变棋子定义后若规则哈希不匹配，会显示“模型空位 · 基础搜索”；未训练模式不借用其他模式权重。
仍可用“载入训练候选”手动选择匹配的 JSON 与 ONNX 文件。
短训候选用于体验与研究，不代表通过棋力验收。揭棋本轮对局点估计有利，置信区间仍很宽。

普通棋谱使用 `.xqgame`，新增模式使用 `.xqlab`，均可在界面保存和载入。
游戏不需要训练检查点、原始数据或 CUDA。模型来源和哈希见 `package-manifest.json`。
目前为本地使用的未签名免安装包，不含自动更新功能。

开发者从项目根目录执行 `npm.cmd run desktop:package` 构建新目录。
新版揭棋、翻棋页面不再显示底部实验工作台；该区域只在变体实验室显示。
构建后运行 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/desktop/create-shortcut.ps1`
可创建或更新当前用户桌面的“弈境”快捷方式。
`desktop-models.json` 声明每种模式的来源；`source` 为 null 或文件缺失时生成空位，
存在但不兼容、哈希不符的文件会阻止打包，不会标为已训练。
历史 `.cmd`、普通夜训入口与数据路径保持兼容。

应用源码随包放在 `source/`。构建需要项目说明中的 Node.js 和 Visual Studio C++ 工具，
原有第三方来源、固定版本和许可证见 `resources/app/THIRD_PARTY_NOTICES.md` 与 `third_party/`。
